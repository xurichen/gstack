# Evaluation Results Log Format

Every scored eval run produces one immutable JSON file generated by `scripts/score-eval.py` (never hand-edited or written by the agent):

`evals/results/{suite}-{variant_id}-{YYYYMMDD-HHMMSS}.json`

## Top-Level Schema

| Field | Type | Description |
|---|---|---|
| `example` | boolean (optional) | Must be `true` for any illustrative sample; omitted or `false` for real runs |
| `date` | string | ISO date (`YYYY-MM-DD`) |
| `git_sha` | string | Commit SHA of the repository under test |
| `model_id` | string | Exact LLM model identifier backing Copilot during the run |
| `stack_versions` | object | Relevant runtime/stack versions (for example `python`, `node`, `spark`, `spring_boot`, `java`) |
| `suite` | string | Suite name (`general`, `spark`, `spring`, or custom) |
| `variant_id` | string | Unique variant identifier |
| `variant_file` | string | Path to the prompt, instruction, or skill file under test |
| `prompt_hash` | string | SHA-256 hash of `variant_file` for exact reproducibility |
| `champion_id` | string or null | Champion identifier compared against (`null` for initial baseline) |
| `human_data_status` | string | `complete` or `incomplete` (validated mechanically by `scripts/score-eval.py`) |
| `tier_summary` | object | Lexicographic pass/regression summary for `human` (Tier 1) and `synthetic` (Tier 2), plus cost guardrail ratio |
| `tasks` | array | Per-task binary pass, tier, primary metric value/delta, and cost telemetry |
| `verdict` | string | One of `promote_champion`, `keep_champion`, `prune`, `rewrite`, `data_incomplete`, `baseline_recorded` |
| `verdict_reason` | string | Deterministic explanation emitted by `scripts/score-eval.py` |

No blended `total_score` field exists. Decisions are strictly lexicographic (Tier 1 human binary gate -> Tier 2 synthetic regression gate -> Tier 1 primary metric delta above 5% timing noise floor -> 2.0x token cost guardrail).
